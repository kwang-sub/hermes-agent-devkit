# Hermes Lite — Default 프로필 직접 개발

루트 `AGENTS.md`가 공통 정책이다. 이 경로에서도 동일하게 default 프로필에서 직접 개발하며 Standard 역할 기반 Dispatch는 사용하지 않는다.

Kanban은 선택적 기록이며 OAuth·세션·기존 데이터/마운트/Worktree를 보존한다. 필요한 경우 `dev-lite-review`, `dev-project-pattern`, `dev-feature-docs`, `git-pr-publish`, `git-workspace-cleanup`, `dev-worktree-create`, `dev-worktree-remove`를 사용한다.
